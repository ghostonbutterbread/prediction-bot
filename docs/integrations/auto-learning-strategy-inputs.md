## Contract and evidence boundary

The default sanitized v1 projection optionally retains the following in `record.market`:

- Root `volume`, `exchange`, `series`, `group`, `event_ticker`, where present, take precedence over corresponding shared-market values. Volume accepts finite numeric JSON values or numeric strings (not booleans); invalid root/shared volumes are audited and do not mask a valid fallback. Zero and otherwise legitimate numeric values are retained without inventing defaults.
- A recognized `shared_candidate.market`: `volume`, `closes_at`, `category`, `exchange`, `series`, `group`, `family`, `event_ticker`, `series_ticker`, and narrow `route` fields. Root `question` and existing validated prices are unchanged. Source-context metadata has its pre-existing canonical allowlist.
- Book envelopes retain `source`, `stage`, `market_id`, `observed_at`, `as_of`, and `data`; data are `best_yes_ask`, `best_yes_bid`, `best_no_ask`, `best_no_bid`, `mid_yes`, `spread`, and `spread_pct`. A usable producer shared generic book takes precedence over a raw generic book, preserving its corrected `synthetic` source; when that shared synthetic book matches the pre-logic book apart from source, it also supplies the pre-logic projection. Otherwise the pre-logic artifact precedes shared evidence. Explicitly post-logic envelopes and generic books matching a retained post-logic envelope (ignoring the producer's source relabel) are omitted and audited; matching is conservative and can omit an identical pre/post book. A direct flat artifact book matching post-logic data is likewise omitted. `market.book_projection_provenance` names each selected book's source path and either `pre_logic` or `generic`; generic is **not** an assertion of pre-decision timing. Unknown/unmarked origins remain unproven, not independently qualified as decision-time evidence. Existing execution snapshot behavior is unchanged.
- Book numeric scalars accept finite JSON numbers and numeric strings (strings are converted to floats); booleans, nulls, nonfinite strings and malformed members are omitted with `invalid_numeric` path entries. If an explicitly present `spread_pct` is invalid, the entire affected book is unavailable with an `invalid_book_spread` omission, rather than letting the legacy strategy silently use its default spread. Other invalid fields are omitted individually. Neither book provenance nor these type checks establish quote validity, fillability or chronology.
- Each selected subtree uses the existing recursive positive-schema sanitizer. It omits and records nested aliases and unknowns; it does not copy recorded actions, probabilities, sizes, outcomes or settlements. `count_missing_strategy_inputs_v1` reports structural missing counts for volume, closes_at, category, exchange, liquidity and the two book envelopes; this is not data-quality, timestamp, or executable-quote qualification. Volume zero is present. Liquidity is never invented and is not projected: the inspected shared-candidate producer does not retain it.

This is an additive **v1** shape for default sanitized projection. Existing saved v1 records and canonical hash verification remain readable without rewriting. Reprojecting an old raw row that contains newly selected fields or changed omission reporting produces different canonical bytes/hash; do not compare reprojected hashes as though projection code were unchanged. A no-new-fields synthetic v1 fixture remained byte-identical to the base, hash `8e31c010aa2c8f135b90dc7a66c380c70fa4751267ea966ba7430524deef1a5c`. The `strict=True` builder remains unchanged, including its current field set and strict validation; these optional extensions apply to the default/source-history sanitized builder, not strict mode. No version upgrade is inferred for historical evidence.

The parent-provided prior audit reports 25/25 selected raw rows with each of the four shared market fields and both book envelopes; liquidity was absent. That is a bounded field-presence observation, not archive-wide coverage, evidence of liquidity/fill, or a source-clock validation. No real archive was opened for this branch. This change does not validate capture, source or availability clocks; in particular a retained book or timestamp does not establish pre-decision availability. Consumers must account for missing fields and establish chronology independently. Market category/series precedence and any datetime parsing are consumer responsibilities. The prior source-only replay remains a reduced diagnostic, not full evaluator parity.
