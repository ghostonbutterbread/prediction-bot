## Intent and contract

Connect frozen, already-compared source-only experiments to the existing `bind_replay_finalized_outcomes` and feedback scorer without running candidate code with later outcomes. `scripts/prepare_research_outcomes.py` requires an unmodified trusted compare receipt naming matched selected identities, its source-input hash, and empty original outcome hash. It validates those against bounded stable files, checks a caller-pinned resolution SHA, runs the existing independent exact-input binder, rehashes all three inputs, and exclusively publishes `receipt.json` last under a new derived output directory. Source files are not edited or copied. Empty resolution data yields zero bound and explicit unbound counts; conflicting identities follow the existing binder's rejection. A later resolution generation uses a distinct output directory.

The comparator receipt and source paths must be protected from the experimental agent. Matching hashes do not authenticate a resolver, prove an untouched holdout, establish historical source time or prove full blindness. The binder loads the complete supplied resolution file in memory: byte budgets are stable-file preflights, not hard memory or I/O limits under concurrent mutation. A failed write may leave an incomplete output directory or a partial `receipt.json`; preserve it and retry in a new output, never treat it as complete without verifying receipt and artifact hashes. Retain the actual immutable source resolution bytes and producer receipt externally: the derived output has pointers and hashes, not a duplicate ledger. Output is retrospective, directional-only diagnostic evidence, not paper settlement or profitability.
