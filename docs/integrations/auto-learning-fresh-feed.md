## Contract

`scripts/fresh_research_feed.py` is an offline, derived-only CLI. It reads and retains the exact manifest bytes once; checks its schema, source/index pairing, and the operator's `--max-index-bytes` **before** scanning; then calls the existing `_verify_archive` and `_verify_index_extent` helpers. The latter makes a whole-committed-prefix digest pass and an independent whole-prefix structural/order pass. It does not substitute suffix-only integrity. Each invocation, including unchanged-checkpoint calls, repeats both full passes. A previous checkpoint additionally incurs a full digest pass over that prior prefix to prove byte continuity. Reverse selection incurs further bounded-block reads. Receipts report these logical byte counts separately from selected raw-payload bytes; they are not physical-device I/O counts and do not include filesystem metadata, parser allocations, imports, or writes. No raw archive is copied or fully rehashed.

CLI requires `--index`, `--manifest`, `--output-root`, one or more `--protected-root` covering all source files, and explicit `--max-index-bytes`, `--max-inspected-rows`, `--max-raw-row-bytes`, `--max-wall-seconds`, `--max-memory-bytes`. The latter is process virtual-address-space RLIMIT_AS, not peak RSS; SIGALRM starts after CLI parsing/imports and bounds subsequent execution, subject to OS/Python signal behavior. Neither is an I/O bandwidth throttle. Selected raw payloads are individually size-checked before allocation, hashed, and checked against canonical index identity. Each accepted row goes through the canonical positive-allowlist `build_replay_decision_input_v1`; no outcomes or independent-event assertions are produced. Outputs are ephemeral task-owned derived `inputs.jsonl`, empty `outcomes.jsonl`, exact `manifest.json`, and `receipt.json` with hashes, row locators and payload/projection hashes, coverage and limits. Output is staged, fsynced, and atomically renamed. The directory name hashes exact receipt bytes. Identical retries verify and reuse the directory, then fsync the output directory and its ancestors before success, including after a previous post-rename fsync failure; a repeated fsync failure is reported. Fsync errors leave publication durability unconfirmed. Concurrent invocations are not coordinated; use one owner and a stable, trusted directory namespace.

No implicit prior state is advanced: the caller supplies its last trusted `--previous <generation>/receipt.json`. Identical manifests return `unchanged`; a changed manifest with zero new index entries returns `manifest_changed_no_new_indexed_data`; appended entries return `new_indexed_data`. A changed prior digest, replaced archive identity, or reduced prior extent produces a `new_generation` error. A row cap produces `truncated`; **initial bootstrap** retains its existing explicit newest-tail-sample checkpoint semantics and does not claim older coverage. For a later truncated delta, retain the same previous checkpoint and pass `--resume <last-page>/receipt.json` for each subsequent page. The pinned manifest is read from that page, not replaced by a newer producer manifest. Each page validates its receipt bytes and page data, previous receipt hash, producer identity/extent, full pinned index digest and structure, prior prefix, and resume boundary against its exact indexed locators. Producer appends are deferred until the next delta; missing or changed pinned files, incompatible producer generation, or bad cursor stop with an error. Resume reads the prior page's compact locators again, adding reverse-index I/O to the repeated full-prefix work.

Only the page that reaches the previous index boundary is `complete` and `checkpoint_eligible`; it advances the high-water to the frozen manifest only when the caller explicitly persists it. Pages are newest to oldest; rows within each page are ascending. A successful page is immutable and idempotently reusable with the same arguments and frozen snapshot, but this CLI cannot atomically commit downstream research effects. The coordinator must durably deduplicate/acknowledge each page by receipt-directory hash, preserve the prior checkpoint and pinned page until consumed, and advance the high-water only after every page has terminal consumption receipts. On crash, retry the same page request until it succeeds, then resume from its receipt; never treat an unacknowledged or fsync-failed directory as completed. A retry without `--resume` after the producer manifest changes may start a different frozen delta and should be used only if no prior page was accepted. Retention/cleanup of consumed ephemeral pages belongs to the coordinator; no new source-copy pipeline is installed.

Rows skipped by canonical projection are counted, not independent history; unchanged manifests cannot establish missing publication continuity, source clocks, outcome availability or learning readiness. A caller-provided previous/page receipt is trusted checkpoint metadata, not cryptographic producer authentication; hashes detect mismatches, not a hostile party able to rewrite the namespace and references. Full compact index integrity does not prove every raw source row was indexed; only hydrated raw rows are verified. The implementation assumes stable index prefix bytes during validation/selection and cooperating collector writer behavior, like the canonical helper; it is not a lock against hostile in-place changes or malicious namespace races.
