## Contract

`scripts/fresh_research_feed.py` is an offline, derived-only CLI. It reads and retains the exact manifest bytes once; checks its schema, source/index pairing, and the operator's `--max-index-bytes` **before** scanning; then calls the existing `_verify_archive` and `_verify_index_extent` helpers. The latter makes a whole-committed-prefix digest pass and an independent whole-prefix structural/order pass. It does not substitute suffix-only integrity. Each invocation, including unchanged-checkpoint calls, repeats both full passes. A previous checkpoint additionally incurs a full digest pass over that prior prefix to prove byte continuity. Reverse selection incurs further bounded-block reads. Receipts report these logical byte counts separately from selected raw-payload bytes; they are not physical-device I/O counts and do not include filesystem metadata, parser allocations, imports, or writes. No raw archive is copied or fully rehashed.

CLI requires `--index`, `--manifest`, `--output-root`, one or more `--protected-root` covering all source files, and explicit `--max-index-bytes`, `--max-inspected-rows`, `--max-raw-row-bytes`, `--max-wall-seconds`, `--max-memory-bytes`. The latter is process virtual-address-space RLIMIT_AS, not peak RSS; SIGALRM starts after CLI parsing/imports and bounds subsequent execution, subject to OS/Python signal behavior. Neither is an I/O bandwidth throttle. Selected raw payloads are individually size-checked before allocation, hashed, and checked against canonical index identity. Each accepted row goes through the canonical positive-allowlist `build_replay_decision_input_v1`; no outcomes or independent-event assertions are produced. Outputs are an ephemeral task-owned derived `inputs.jsonl`, empty `outcomes.jsonl`, exact `manifest.json`, and `receipt.json` with hashes, row locators and payload/projection hashes, coverage and limits. Output is staged, fsynced, and atomically renamed; repeat of the same arguments verifies and reuses the directory. A failure after rename but before parent fsync leaves a complete-looking directory with durability unconfirmed. Concurrent invocations are not coordinated; use one owner and a stable, trusted directory namespace.

No implicit prior state is advanced: the operator passes the last trusted `--previous <generation>/receipt.json`. Identical manifests return `unchanged`; a changed manifest with zero new index entries returns `manifest_changed_no_new_indexed_data`; appended entries return `new_indexed_data`. A changed prior digest, replaced archive identity, or reduced prior extent produces a `new_generation` error, not silently accepted continuity. A row cap produces `truncated` and a partial result. **Initial bootstrap** deliberately permits a newest-tail sample to be used as the subsequent checkpoint while marking `complete: false`; older uninspected entries are not claimed covered. A truncated later delta is not checkpoint-eligible: retry against the last complete checkpoint with a higher cap. Rows skipped by canonical projection are counted, not independent history; unchanged manifests cannot establish missing publication continuity, source clocks, outcome availability or learning readiness. A caller-provided previous receipt is trusted checkpoint metadata, not cryptographic producer authentication. Full compact index integrity does not prove every raw source row was indexed; only hydrated raw rows are verified. The implementation assumes stable index prefix bytes during validation/selection and cooperating collector writer behavior, like the canonical helper; it is not a lock against hostile in-place changes or malicious namespace races.
